# بینا – سیستم پرسش و پاسخ Excel

این مخزن شامل یک رابط وب ایستا برای مرور مکالمات و همچنین یک هسته پایتونی برای اجرای پرسش‌های متنی بر روی فایل‌های اکسل است.

## نصب پیش‌نیازها

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## اجرای سیستم پرسش و پاسخ

```bash
python main.py مسیر/به/فایل.xlsx "جمع فروش سال 1402 جایی که استان=تهران"
```

برای ورود به حالت تعاملی کافی است سؤال را مشخص نکنید:

```bash
python main.py مسیر/به/فایل.xlsx
```

برای دریافت خروجی JSON نیز می‌توانید از گزینه `--json` استفاده کنید.

## اجرای رابط وب در یک محیط کاربری ساده

برای مشاهده رابط کاربری HTML می‌توانید فایل `index.html` را مستقیماً در مرورگر باز کنید. اگر بخواهید آن را روی یک سرور محلی اجرا کنید تا جست‌وجو و بارگذاری منابع به‌درستی انجام شود، از یک سرور ساده‌ی پایتونی استفاده کنید:

```bash
python -m http.server 8000
```

سپس در مرورگر آدرس [http://localhost:8000/index.html](http://localhost:8000/index.html) را باز کنید. با این روش بدون نیاز به تنظیمات پیچیده می‌توانید رابط کاربری را در یک محیط ساده اجرا و بررسی کنید.
