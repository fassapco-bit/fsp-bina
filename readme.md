# بینا – سیستم پرسش و پاسخ Excel

این مخزن شامل یک رابط وب ایستا برای مرور مکالمات و همچنین یک هسته پایتونی برای اجرای پرسش‌های متنی بر روی فایل‌های اکسل است.

## نصب پیش‌نیازها

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## اجرای سیستم پرسش و پاسخ

```bash
python main.py مسیر/به/فایل.xlsx "جمع فروش سال 1402 جایی که استان=تهران"
```

برای ورود به حالت تعاملی کافی است سؤال را مشخص نکنید:

```bash
python main.py مسیر/به/فایل.xlsx
```

برای دریافت خروجی JSON نیز می‌توانید از گزینه `--json` استفاده کنید.
